## Waveshare RLCD 4.2

| 项目 | 说明 |
| --- | --- |
| 屏幕 | 400×300 黑白反射式 LCD（ST7305），无背光、无残影 |
| 翻页交互 | KEY 上一页、BOOT 下一页，长按 KEY 进入或退出设置 |
| 显示内容 | 主页：DeepSeek 余额 + MiniMax 的 5H / WEEK 用量；时钟页：时间 + 余额 + 正在播放的歌名、歌手与歌词；详情页、音乐页、会话页、设置页 |
| 告警 | MiniMax 5H 达到 95% 时全屏反相页，可选提示音；档位可在设备设置页或控制页（`alert.set.v1`）修改并持久保存 |
| 断连保留最后数据 | ✅ 离线时保留数值并显示 OFFLINE 标识 |
| 时钟 | ✅ PCF85063 RTC，由 Bridge 通过 `time.sync.v1` 下发 |
| 温湿度 | ✅ SHTC3（时钟页） |
| 电量 | ✅ 电压线性估算，无充电状态 |
| 亮度 | 反射屏没有背光：设置页只有四行（不含亮度），也不声明 `brightness.set.v1` |
| 屏幕方向 | ✅ 设置内切换（横向 / 竖向 / 翻转）；三种方向下页面集合相同，各页面都有对应版式 |
| 托盘/菜单栏左键切换时钟 | ✅ `screen.toggle.v1` |
| 滚轮翻页 | ✅ `screen.page.v1` |
| 网易云正在播放 | ✅ `nowplaying.v1`（macOS Bridge）：歌名、歌手、进度与当前行歌词；中文用内置 12×12 点阵字库，离线保留最后一首 |
| Claude Code 会话 | ✅ `sessions.v1` / `sessions.v2` / `sessions.v3`：运行中会话的会话名与状态（空闲、忙碌、等待你、后台 shell），等待时给出原因（提问、权限、沙箱、后台 worker、目标确认、对话框）；状态一变即推送，只在收到第一条会话数据后进入页面环；名单可超过 4 行，面板画出能画的那几行，计数按整份名单算 |
| BLE OTA | ✅ `ota.folder.v1` |
| Web 烧录器 | ✅ |

音乐页只在 macOS 上取数：Bridge 读客户端自己的本地播放记录与公开歌词接口，不需要账号凭据，也不需要屏上有人操作；没有正在播放的音乐时不推送。会话页读本机 `~/.claude/sessions` 下 Claude Code 自己的会话状态，只把会话名、状态和等待原因推给面板；会话 ID、工作目录、git 分支和对话内容都不离开电脑。只声明 `sessions.v1` 的固件拿到的是两态词表，`sessions.v2` 才带上等待与会话的后台 shell，`sessions.v3` 才拿到超过 4 行的整份名单。所有页面显示的是同一套用量语义：MiniMax 的 5 小时与周额度给出已用百分比、进度条与重置倒计时；DeepSeek 只公开余额，因此显示账户剩余金额而不是百分比。表中的固件能力只描述设备侧；左键切换时钟与滚轮翻页在 Windows 托盘和 macOS 菜单栏都已支持，两端都提供固件 OTA 入口，安装需桌面确认及设备物理确认。

当前实机验证范围和完整操作见 [RLCD 4.2 说明](../firmware/targets/waveshare_rlcd_42/README.md)。

## Waveshare AMOLED 1.8（V1）

| 项目 | 说明 |
| --- | --- |
| 屏幕 | 368×448 AMOLED（SH8601，QSPI），黑色像素熄灭发光 |
| 翻页交互 | 触摸向左滑下一页、向右滑上一页、轻点回主页、原地按住 800 ms 进设置；会话页里上下滑动翻看整份会话名单；BOOT 键短按回主页、长按进设置 |
| 显示内容 | 与 RLCD 4.2 相同的页面环与设置页；收到第一条会话数据后，会话页进入环 |
| 告警 | MiniMax 5H 达到 95% 时全屏反相页，轻点或滑动关闭；提示音暂为静音（ES8311 未接线） |
| 断连保留最后数据 | ✅ 离线时保留数值并显示 OFFLINE 标识 |
| 时钟 | ✅ PCF85063 RTC，由 Bridge 通过 `time.sync.v1` 下发 |
| 电量 | ✅ AXP2101 电量计直接读数 |
| 亮度 | ✅ `brightness.set.v1`：控制页 0–100% 拖动即下发（0 关闭屏幕），设备设置页按 OFF / 20% / 40% / 60% / 80% / 100% 步进并持久保存 |
| 屏幕方向 | ✅ 设置内切换（0° / 90° / 180°）；滑动方向跟随设置 |
| 托盘/菜单栏左键切换时钟 | ✅ `screen.toggle.v1` |
| 滚轮翻页 | ✅ `screen.page.v1` |
| 网易云正在播放 | ✅ `nowplaying.v1`（macOS Bridge） |
| Claude Code 会话 | ✅ `sessions.v1` / `sessions.v2` / `sessions.v3`：摘要行（含等待计数）、状态色条、状态芯片与会话名，等待时在名字后给出原因；行序为最近更新在前；状态一变即推送，只在收到第一条会话数据后进入页面环；名单超过一屏时上下滑动翻看，右上角显示当前显示的区间 |
| BLE OTA | ✅ `ota.folder.v1` |

只适配 V1 硬件（SH8601 + FT3168）；V2（CO5300 + CST820）是另一块屏。当前为 hardware
bring-up 状态，实机验证范围见 [目标说明](../firmware/targets/waveshare_amoled_18/README.md)。

## 屏幕快捷操作

- **RLCD 4.2**：KEY 上一页，BOOT 下一页，长按 KEY 进入或退出设置；设置中 KEY 选择项目、BOOT 修改选项。KEY 可关闭当前用量告警。OTA 待确认时 KEY 确认，长按 KEY 拒绝。
- **AMOLED 1.8**：向左滑下一页，向右滑上一页，轻点回主页，按住 800 ms 进出设置；设置中滑动选择项目、轻点换行、按住退出。会话页里上下滑动翻看整份会话名单。告警页与 OTA 确认页用轻点确认、按住拒绝。
- **Windows 托盘与 macOS 菜单栏**：左键切换支持设备的时钟；鼠标悬停在 Bridge 图标上滚动，上滚查看上一页，下滚查看下一页，页面集合与顺序由各设备决定。操作作用于所有已连接且支持该命令的设备；设备处于时钟时会先回到额度页面。快速连续滚动会限速，OTA 期间不执行翻页。
- 滚轮翻页要求设备通告 `screen.page.v1`；未通告的设备只接收其支持的命令。
